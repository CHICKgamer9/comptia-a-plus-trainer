# Raster figures (optional)

Prefer labelled SVG diagrams in `src/components/teach-diagrams.tsx`.

If you need a photo or scan:

1. Drop a compressed WebP/PNG here (keep under ~150 KB).
2. Reference it with `imageFigure("/figures/your-file.webp", "alt", "caption")` on a lesson section or project step.

Do not commit large MP4s — use a YouTube/Vimeo `videoFigure` instead.
